## Описание задачи

**Вариант 30** — E-commerce + HR (эталон преподавателя)  
**Бизнес-задача:** Оценка ниши деловой литературы: ассортимент и цены конкурента плюс доступность кадров для запуска направления.

**Задачи исследования:**
1. Спроектировать вежливый сбор данных через открытый REST API (пагинация, заголовки `User-Agent`, паузы между запросами, повторные попытки `Retry`, кэширование и обработка ошибок).
2. Извлечь данные из статических HTML-страниц двумя независимыми способами — CSS-селекторами (`BeautifulSoup4`) и выражениями `XPath` (`lxml`) — и сверить результаты.
3. Очистить и нормализовать «грязные» текстовые поля (цены, остатки, рейтинги, зарплатные вилки, даты, навыки в тексте требований) с помощью регулярных выражений (`re`).
4. Сформировать итоговые таблицы `pandas.DataFrame`, провести разведочный анализ данных (EDA) и построить визуализации.
5. Сформулировать управленческие выводы и рекомендации на основе рассчитанных показателей.

**Источники данных:**
1. **REST API:** Портал «Работа в России» (`http://opendata.trudvsem.ru/api/v1/vacancies`)  
   - Параметры: поисковый запрос `text="аналитик данных"`, `pages=3`, `per_page=100` (собрано 300 вакансий).
2. **Веб-парсинг (HTML):** Учебная витрина книжного интернет-магазина `https://books.toscrape.com`  
   - Параметры: категория `business_35` + расширение смежной категорией `nonfiction_13`, `pages=3` (собрано 52 карточки книг).

**Целевые метрики и визуализации:**
- Медиана и квартили цен (`£30.93`, IQR `£20.27`), доля товаров в наличии (`100%`), средний рейтинг (`3.02★`).
- Распределение цен в разрезе рейтинга книг (1–5★).
- Медиана зарплатной вилки по регионам РФ (общая медиана — `59 300 ₽`, доля вакансий с указанной зарплатой — `97%`).
- Топ-10 востребованных навыков и технологий в требованиях к кандидатам (`SQL`, `Excel`, `1С`, `Python`, `Power BI` и др.).
